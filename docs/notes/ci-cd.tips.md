# CI/CD

業務では単体テストを組む意味を上層部に理解させることが私にはできないので、本格的にCI/CDを入れてあげることができないので個人として入れてみた。当然初めて。技術評論社の「Gihub CI/CD実践ガイド」を読んでやってみたがこちらの本はかなりわかりやすかった。後半はかなり高給な内容だったので自分にはまだまだだったが、とはいえテストの実行ぐらいなら問題なくできそうと感じたし、実際できた。今回はTestだけしかやってないが、実際はLinterもやれたほうがよさそう。

ただ、可搬性がよくないなあと思う。自分なりのルールを決めてどのリポジトリでも同じファイルでテストが実行できるようになると一番いいんだろうが、ファイルベースなのかカスタムアクションとかを作ってしまったほうがいいのかの知見がまだまだない。

バージョンに関連することは書く際にちゃんと公式ドキュメントを参考にしたほうがよさそう。2024の本でもv4が推奨されていたが、すでにv7まででいるようだし、.NETの公式ドキュメントのサンプルでさえちょっと古いバージョンを使っている。この辺りは今回使ってないがdependabotを使って監視できるようになるんだろうか。この辺りは調査が必要そう。

Nugetパッケージとして公開するものはほぼ公式ドキュメントをコピペで問題なかった。思ったより簡単。とはいえTagがついたら自動で実行とかは怖すぎたので、マニュアル実行にしておいた。
