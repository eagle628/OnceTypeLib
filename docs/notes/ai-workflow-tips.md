# AI駆動開発のTIPS

## 所感

AIのみによる開発というものを実施してみた。[設計書](../DesignDoc.md)をベースにほぼすべてのコードをAIで作らせるようにしてみた。ライブラリの目的が単純であることもあり、AIのみによる開発は十分に早く高品質と感じる。実際並列して人力で作ったものとほぼ同じコードが生成される。以前だとConcurrency周りやLockに無駄が多かったように感じていたが、相当いい気がする。また、速度はやはり人力とは比べ物にならない。自分のスタイルが知っているAPIでも毎回公式Docを確認するやり方ということもあって速度は遅め（品質は高いと信じたい）ということもあるのでスタイルによってはその差は縮まるだろう。設計書を作る段階でもかなり壁打ち役として優秀だった。Extensionは文法レベルで走っていてもなかなか普通のクラス設計では使わないOr使っても外部ライブラリの拡張ぐらいで、ライブラリの設計時にそういう使い方ができるというのはかなり発見だった。

今回のコードは全体的に古めの実装（.NET Standard系）ということもあり、最新のAPIを使わないので目立たたなかったが、公式のドキュメントでは最新のものを使わない問題はどうすれば回避できるのだろうか。Agentベースだともう少し回避できるのだろうか。

自分がNugetパッケージとして公開するのが初めてで、マルチターゲットなアプリを作ったことがなかったが、そのあたりについてはかなり高精度で実装してくる。Testについても同様でTestRunnerベースの切り替えとかも当然やってくる。設計さえできれば割となんでも作ってくれそうだなあと感じる。次はもう少し複雑なライブラリを作ってみたいと思う。
